# Suhalaya — Blog / Travel Journal Strategy

## 1. Category structure (= mega-menu clusters, see IA doc §4)
1. **Corporate & Chauffeur Mobility** — educates HR/admin/corporate buyers, ranks for B2B search intent
2. **Outstation Self-Travel With Chauffeur** — ranks for South India road-trip search intent, top-of-funnel leisure traffic
3. **Corporate Events, Weddings & Special Journeys** — ranks for planner/event-organiser intent

Using the same 3 clusters as the services mega-menu means every blog post has an obvious service page to link to, and every service page has an obvious blog cluster to pull "Related blogs" from — this is what makes the blog a lead-gen system rather than a content dump.

## 3. Per-post system requirements (enforced by Template E)
- Every post tagged to exactly one of the 3 categories.
- Every post links to 1–2 relevant service pages and, where applicable, 1 package page.
- Mid-article CTA is contextual (an employee-transport post CTAs to "Employee Transportation," not a generic "Contact Us").
- No copied content from Avis/ECO or any third party — original writing only, informed by the positioning in `00-project-brief.md`.

## 4. Success metric framing (for later, not build-blocking)
Track by cluster: which cluster drives Corporate Enquiry submissions vs. Request-a-Quote (leisure) submissions — this should inform which Wave 4+ topics get written next.
